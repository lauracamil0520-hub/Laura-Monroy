# Actividad 2: Hands on - Configuración de herramientas

## Introducción

Este repositorio contiene los documentos y las evidencias correspondientes a la Actividad 2, relacionada con la instalación, configuración y utilización de Git y GitHub.

## Objetivo

Comprender el funcionamiento de Git y GitHub mediante la creación de un repositorio, la gestión de archivos y el registro de cambios utilizando los comandos principales de Git.

## Contenido del repositorio

- **Capítulo 1:** Introducción a Git y GitHub.
- **Capítulo 2:** Instalación y configuración inicial de Git.
- **Informe de proceso:** Descripción de las actividades realizadas, evidencias, dificultades, soluciones y conclusiones.
- **registro_proceso.txt:** Archivo de prueba utilizado durante la práctica.

Los documentos se elaboran en Word y se exportan a PDF para su consulta y entrega.

## Herramientas utilizadas

- Git.
- GitHub.
- Termux en Android.
- Microsoft Word.
- Navegador Chrome.

## Comandos utilizados

- `git --version`: comprobar la versión instalada de Git.
- `git config --global --list`: verificar la configuración inicial.
- `git clone`: clonar un repositorio.
- `git status`: consultar el estado del repositorio.
- `git add`: preparar archivos para registrar cambios.
- `git commit`: guardar los cambios en el historial.
- `git push`: enviar los cambios al repositorio remoto.

## Conclusión

Esta actividad permitió conocer y practicar las funciones básicas de Git y GitHub, comprender cómo se gestionan los archivos y aprender a registrar y publicar cambios en un repositorio remoto.
